# Essai Web UI 스펙

## 개요

Next.js 15 (app router) + Tailwind CSS. 로컬 서버 (localhost:7331). 인증 없음.

## API 라우트

```
GET  /api/config              ProjectConfig.load()
POST /api/config              ProjectConfig.save()

GET  /api/bible               bible/ 전체 파일 로드
POST /api/bible/:section      개별 파일 저장

GET  /api/chapters            챕터 목록
GET  /api/chapters/:n         챕터 내용
POST /api/chapters/:n/write   챕터 생성 (SSE)
POST /api/chapters/:n/rewrite 챕터 재생성 (SSE)
POST /api/chapters/:n/review  ChapterReviewer 피드백

GET  /api/status              진행 상황
POST /api/export              전체 내보내기

POST /api/bible/agent         BibleAgent (SSE)
```

## 기술 스펙

- Next.js 15 app router
- Tailwind CSS (다크 테마)
- @essai/core workspace:*
- SSE (Server-Sent Events) for streaming
- localStorage for project path

## CLI 연동

```bash
essai serve [--port 7331]
```

packages/cli/src/commands/serve.ts에서 Next.js dev 서버 실행.
